How it picks

Week by week from home. Every Saturday starts and ends at your door, so each letter is a separate problem: take the nearest parkrun with that letter. A repeated letter, like the two Ns in ANNA, takes the nearest and then the next nearest, because no parkrun can count twice.

Back to back. Here you travel from each parkrun straight to the next, so the choices depend on each other. The closest J might be a long way from any A. The tool tries every route through the letters at once with a technique called dynamic programming: for each letter, it remembers the cheapest way of reaching each possible parkrun. If a name repeats a letter and the best route uses the same parkrun twice, it rules that parkrun out for one of the positions, tries again and keeps the best result.

Event names and locations come from parkrun’s official event list as of 4 November 2026 (899 Saturday 5k events in England, Scotland, Wales, Northern Ireland, Jersey, Guernsey and the Isle of Man). Island events are counted, but the distances to them are straight lines across the sea, so plan the ferry yourself.
